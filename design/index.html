The rules in one glance

  • Violet is for state only; selected things are soft grey.
  • No blue or black filled buttons.
  • Corners slightly filleted, never pills; nothing bounces.
  • Hand-drawn ticks, not iOS switches.
  • No keyboard shortcuts: they clash with Rhino.
  • The agent only gets what you send it (AI or Send to agent).
  • A pen stroke is a sketch, never ink.
  • No explanation text under buttons, no black hint bars.
  • Hover shows the Rhino layer name, never an invented one.
  • Light / dark changes Crayon only, never Rhino.
