# rhino-sketching-tool

## Design

The interface design for **Crayon** is in [`design/`](design/README.md): a working prototype, design tokens, component specs, the logo, icons and docs.

- Start page: [`design/index.html`](design/index.html)
- Prototype: [`design/prototype/index.html`](design/prototype/index.html) (add `?frame=rhino` to see it inside a Rhino 8-style window)
- To build it: [`design/specs/README.md`](design/specs/README.md)

To browse everything locally, run `python -m http.server 5173` in this folder and open `http://localhost:5173/design/`.
