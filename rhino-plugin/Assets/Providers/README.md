# Provider logos

Downloaded from their owners' official sites:

- `claude.svg`: https://claude.com/icon.svg (linked from https://claude.com/).
- `openai-black.svg` and `openai-white.svg`: unmodified monoblossom SVGs from
  https://cdn.openai.com/brand/OpenAI-Logos-2025.zip, referenced by
  https://openai.com/brand/.

Claude's logo belongs to Anthropic; OpenAI's logos belong to OpenAI. These images
identify the available assistant providers and do not indicate endorsement.

The chooser in `UI/Web/agent.html` includes these files as base64 image data so it
does not need a network connection. If replacing an asset, update its embedded copy.
